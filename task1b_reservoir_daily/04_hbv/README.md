# HBV

- กลุ่ม: Hydrology (Conceptual)
- ทำอะไร: แบบจำลองลุ่มน้ำของ SMHI จำความชื้นดินได้
- ข้อมูลที่ใช้: ฝน + อุณหภูมิ/การระเหย
- สถานะ: ยังไม่เริ่ม

## หลักการ
Conceptual model ของสวีเดน (SMHI) แบ่งเป็น 3 ส่วน: ความชื้นดิน (soil moisture), ถังน้ำผิวดินด้านบน (เร็ว) และถังน้ำใต้ดิน (ช้า) ฝนที่ซึมลงดินมากน้อยขึ้นกับว่าดินชุ่มแค่ไหน

## สูตร
- น้ำที่ไหลลงถังบน (recharge) = P × (SM / FC)^β
- FC = ความจุความชื้นดินสูงสุด, β = ความโค้ง
- ส่วนที่เหลือ P − recharge เก็บไว้ในดิน
- น้ำท่า Q = k₀·max(UZ−L,0) + k₁·UZ + k₂·LZ (UZ = ถังบน, LZ = ถังล่าง)

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
ฝน P = 20 mm, ความชื้นดิน SM = 150 mm, FC = 250 mm, β = 2
- recharge = 20 × (150/250)² = 20 × 0.36 = **7.2 mm**
- เก็บในดิน = 12.8 mm → SM ใหม่ = 162.8 mm
- ถ้าวันถัดไปฝน 20 mm อีก recharge = 20 × (162.8/250)² = 8.48 mm (มากขึ้นเพราะดินชุ่มขึ้น)
- ถังบน UZ = 7.2 mm, k₁ = 0.1 → วันนั้นไหลออก 0.72 mm

## ใช้ในโปรเจกต์นี้อย่างไร
ใช้ฝนรายวัน + อุณหภูมิ/การระเหย calibrate ต่ออ่าง เทียบกับ GR4J ใน backtest
