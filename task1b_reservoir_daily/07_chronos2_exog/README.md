# Chronos-2 + ฝนพยากรณ์

- กลุ่ม: Deep Learning (Foundation Model)
- ทำอะไร: ตัวเทียบแบบไม่ต้องฝึก
- ข้อมูลที่ใช้: inflow + ฝน
- Lag: ประวัติทั้งหมด + ฝนพยากรณ์ 7 วัน
- สถานะ: ใช้งานได้ ทดสอบกับข้อมูลจริงแล้ว

## หลักการ
Chronos-2 แบบ zero-shot (ไม่ต้อง train) ที่รับตัวแปรอนาคตที่รู้ล่วงหน้า (future covariates) คือฝนพยากรณ์ 7 วัน ช่วยตอบว่าโมเดลที่เรา train เองดีกว่า Foundation model สำเร็จรูปหรือไม่

## สูตร
context = inflow 90 วันล่าสุด / mean(|context|) → Transformer + ฝนพยากรณ์ → quantile อนาคต × mean(|context|)

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
inflow 90 วันล่าสุดเฉลี่ย 2.5 MCM/วัน โมเดลให้วันที่ 1 ในสเกลมาตรฐาน P10/P50/P90 = 0.6/1.2/2.4
- แปลงกลับ = 1.5 / **3.0** / 6.0 MCM/วัน

## ใช้ในโปรเจกต์นี้อย่างไร
ตัวเทียบ ต้องติดตั้ง torch
