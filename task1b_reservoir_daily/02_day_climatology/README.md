# ค่าเฉลี่ยวันเดียวกันในอดีต

- กลุ่ม: Baseline
- ทำอะไร: ค่าเฉลี่ยของวันเดียวกันของปี
- ข้อมูลที่ใช้: inflow อย่างเดียว (Baseline)
- Lag: ไม่มี Lag: ค่าเฉลี่ยวันเดียวกันในอดีต
- สถานะ: ใช้งานได้ ทดสอบกับข้อมูลจริงแล้ว

## หลักการ
ใช้ค่ากลางของวันเดียวกันของปีจากทุกปีในอดีต แต่ข้อมูลรายวันแกว่งมาก จึงเฉลี่ยแบบหน้าต่างเลื่อน ±7 วันรอบวันนั้น (รวม 15 วันต่อปี) ให้ค่าเรียบขึ้น

## สูตร
ŷ(วัน d) = Median { y(ปี k, วัน d−7 … d+7) ทุกปี k ในชุด train }
P10 / P90 อ่านจากชุดเดียวกัน

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
อยากทาย 25 ต.ค. ใช้ข้อมูล 18 ต.ค.–1 พ.ย. ของ 20 ปี = 300 ค่า
ถ้าเรียงแล้ว Median = 2.1, P10 = 0.6, P90 = 6.5 MCM/วัน → พยากรณ์ 25 ต.ค. = 2.1 (ช่วง 0.6–6.5)

## ใช้ในโปรเจกต์นี้อย่างไร
Baseline ตัวที่สอง และใช้เป็นค่าตั้งต้นในวันที่ไม่มีฝนพยากรณ์
