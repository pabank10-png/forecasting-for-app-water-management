# HEC-HMS (ใช้เทียบ)

- กลุ่ม: Hydrology (Conceptual)
- ทำอะไร: แบบจำลองฝน → น้ำท่า ตามวิธีของ HEC-HMS (USACE) เขียนเป็น Python ใช้เทียบกับ GR4J และ HBV
- ข้อมูลที่ใช้: ฝน + การระเหย
- สถานะ: ใช้งานได้ ทดสอบกับข้อมูลจริงแล้ว

## หลักการ
HEC-HMS ให้เลือกวิธีคำนวณแต่ละส่วนได้ ที่นี่ใช้ชุดที่ HEC-HMS แนะนำสำหรับจำลองต่อเนื่องหลายปี (continuous) เพราะ SCS Curve Number เหมาะกับพายุลูกเดียว
- Loss: Deficit and Constant ดินมี "ช่องว่าง" (deficit) ได้สูงสุด dmax มม. ฝนเติมช่องว่างก่อน วันแล้งการระเหยทำให้ช่องว่างกลับมา เมื่อดินเต็มแล้ว น้ำซึมลงได้วันละ f มม. ที่เหลือไหลบ่า
- Transform: SCS unit hydrograph (สามเหลี่ยม) Tp = 0.5 + lag วัน ฐานกราฟ 2.67·Tp
- Baseflow: Linear reservoir น้ำที่ซึมลงส่วน g เข้าถังน้ำใต้ดิน ปล่อยออกวันละ G/k

พารามิเตอร์ 5 ตัว (dmax, f, lag, k, g) และพื้นที่รับน้ำ ปรับให้ KGE ของ √inflow ดีที่สุด เหมือน GR4J/HBV

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
dmax = 150 มม., ช่องว่างตอนนี้ D = 30 มม., f = 5 มม./วัน, ฝน 50 มม., ระเหย 4 มม.
- ฝนสุทธิ 46 มม. เติมช่องว่าง 30 มม. เหลือ 16 มม.
- ซึมลง 5 มม. ไหลบ่า **11 มม.** กระจายเข้าอ่างตาม unit hydrograph ในวันถัดๆ ไป
- ลุ่มน้ำ 300 km² → 11 × 300 / 1000 = **3.3 MCM**
