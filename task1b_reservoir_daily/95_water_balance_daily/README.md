# Water Balance รายวัน

- กลุ่ม: Water Balance
- ทำอะไร: ปริมาตรพรุ่งนี้ = วันนี้ + inflow − ระบาย − ใช้/ระเหย เกินความจุ → ล้น spillway
- ข้อมูลที่ใช้: inflow พยากรณ์ + ความจุ/spillway
- สถานะ: ใช้งานได้ ทดสอบกับข้อมูลจริงแล้ว

## หลักการ
สมดุลน้ำรายวัน: ปริมาตรพรุ่งนี้ = วันนี้ + น้ำเข้า − น้ำระบาย − ใช้/ระเหย ถ้าเกินความจุ ส่วนเกินคือน้ำล้น spillway (ซึ่งต้องไม่เกินความสามารถของ spillway)

## สูตร
S(t+1) = S(t) + Q_in − Q_out − E
ถ้า S(t+1) > capacity: spill = S(t+1) − capacity (จำกัดไม่เกิน spillway capacity ต่อวัน) แล้ว S(t+1) = capacity

## ตัวอย่างการคำนวณ (ข้อมูลจริง อ่างหนองปลาไหล)
23 ต.ค. 2026 มีน้ำ 179.27 MCM, วันที่ 24 inflow 3.34, ระบาย 2.14
- 179.27 + 3.34 − 2.14 = **180.47 MCM** ตรงกับค่าจริงที่ RID รายงาน 180.46 (ต่างจากการปัดเศษ)
ตอนนี้ปริมาตรอยู่ราว 110% ของความจุที่ระดับเก็บกักปกติ (ประมาณ 163.8 MCM) แปลว่าน้ำอยู่เหนือระดับเก็บกักแล้ว ถ้าพยากรณ์ inflow 7 วัน 20.65 MCM และระบายวันละ 2.14 → ปริมาตรจะเพิ่ม 20.65 − 14.98 = +5.67 MCM จึงต้องดูความสามารถ spillway ประกอบ

## ใช้ในโปรเจกต์นี้อย่างไร
ต้องมีค่าความจุ ระดับเก็บกัก และ spillway capacity ของแต่ละอ่าง (ยังต้องรวบรวม) ผลน้ำล้นส่งต่อให้งาน 2
