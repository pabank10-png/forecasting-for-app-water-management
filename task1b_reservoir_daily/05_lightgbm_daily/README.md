# LightGBM quantile รายวัน

- กลุ่ม: Machine Learning (Gradient-Boosted Trees)
- ทำอะไร: ฝนย้อนหลัง + ฝนพยากรณ์ + ความชื้นดิน + ปริมาตรอ่าง
- ข้อมูลที่ใช้: inflow + ฝน + ปริมาณน้ำในอ่าง + ฤดูกาล
- Lag: inflow lag 1/2/3/7 | ฝนรวม 1/3/7/30 วัน | ปริมาณน้ำ lag 1
- สถานะ: ใช้งานได้ ทดสอบกับข้อมูลจริงแล้ว

## หลักการ
เหมือน LightGBM ของงาน 1 แต่รายวัน และ train 1 โมเดลต่อระยะล่วงหน้า (h = 1…7 วัน) ใช้ตัวแปร: ฝนย้อนหลัง 1/3/7 วัน, ฝนพยากรณ์ของวันเป้าหมาย, ความชื้นดิน, inflow เมื่อวาน และปริมาตรอ่าง

## สูตร
ŷ_h = ค่าเริ่มต้น + η·Σ treeₖ(x) แยกโมเดล P10/P50/P90 ด้วย Pinball loss (ดู README ของ `task1_reservoir_monthly/05_lightgbm_quantile`)

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ โมเดล h = 1 ของอ่างหนองปลาไหล)
ค่าเริ่มต้น 1.0 MCM/วัน, η = 0.1, inflow วันนี้ = 3.34 (ข้อมูลจริง 24 ต.ค.)
- tree₁: inflow เมื่อวาน > 3 → +15
- tree₂: ฝนพยากรณ์พรุ่งนี้ > 30 mm → +12 สมมติฝนพยากรณ์ 10 mm → −3
- tree₃: ความชื้นดิน > 0.45 → +4
- P50 = 1.0 + 0.1×(15 − 3 + 4) = **2.6 MCM/วัน**
