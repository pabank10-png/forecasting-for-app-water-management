# LSTM / Seq2Seq รายวัน

- กลุ่ม: Deep Learning (Neural Network)
- ทำอะไร: encoder อ่านฝนจริง decoder อ่านฝนพยากรณ์
- ข้อมูลที่ใช้: ข้อมูลรายวัน + ฝนพยากรณ์
- สถานะ: ยังไม่เริ่ม

## หลักการ
LSTM 2 ส่วน ส่วนแรก (encoder) อ่านอดีต 30–90 วัน (ฝนจริง inflow ความชื้นดิน) แล้วสรุปเป็น "สถานะลุ่มน้ำ" ส่วนที่สอง (decoder) อ่านฝนพยากรณ์ทีละวันข้างหน้าแล้วออกค่า inflow วันที่ 1…7

## สูตร
encoder: (h, c) = LSTM(x_อดีต) → decoder: เริ่มจาก (h, c) แล้ว ŷ(t+k) = W·LSTM(rain_พยากรณ์(t+k)) + b
ภายใน LSTM: c = f·c_เก่า + i·c̃, h = o·tanh(c) (ดูตัวอย่างใน `task1_reservoir_monthly/09_lstm`)

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ 1 หน่วย)
encoder จบที่ c = 0.95 (ลุ่มน้ำชุ่ม) วันที่ 1 decoder รับฝนพยากรณ์ 40 mm: f = 0.9, i = 0.5, c̃ = 0.8, o = 0.7
- c = 0.9×0.95 + 0.5×0.8 = 1.255
- h = 0.7×tanh(1.255) = 0.7×0.850 = 0.595
- ŷ = 0.5 + 6×0.595 = **4.07 MCM/วัน**

## ใช้ในโปรเจกต์นี้อย่างไร
train รวมทุกอ่างพร้อมกัน (ใส่รหัสอ่างเป็น input) เพราะข้อมูลแต่ละอ่างไม่มากพอสำหรับ Deep Learning
