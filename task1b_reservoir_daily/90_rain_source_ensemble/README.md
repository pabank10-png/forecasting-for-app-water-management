# รันทุกโมเดลด้วยฝนแต่ละค่าย

- กลุ่ม: Post-processing
- ทำอะไร: ECMWF / GFS / ICON / JMA / TMD แยกกัน ได้ช่วง inflow ต่ำ–สูงและโอกาสอ่างล้น
- ข้อมูลที่ใช้: inflow + ฝนพยากรณ์แยกรายค่าย
- Lag: ตามโมเดลฐาน
- สถานะ: เขียนโค้ดแล้ว ยังไม่ได้รันกับข้อมูลจริง (ต้องมีฝนพยากรณ์ 7 วันแยกรายค่ายที่เก็บย้อนหลังไว้)

## หลักการ
ฝนพยากรณ์แต่ละแหล่งไม่เหมือนกัน จึงรันโมเดล inflow ทีละแหล่ง (ECMWF, GFS, ICON, JMA, TMD) แล้วดูการกระจายของผล ได้ช่วงต่ำ–สูงและ "โอกาสอ่างล้น" = สัดส่วนแหล่งที่ทำให้ปริมาตรเกินความจุ แหล่งที่แม่นในอดีตได้น้ำหนักมากกว่า

## สูตร
- ช่วง = [min, max] หรือ P10/P90 ของผล 5 แหล่ง
- P50 = Σ wₛ·ŷₛ (wₛ จาก inverse-MAE ของแต่ละแหล่ง)
- โอกาสล้น = Σ wₛ × [S_ปลาย,ₛ > capacity]

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ inflow รวม 7 วันของอ่างหนองปลาไหล)
ECMWF 18, GFS 25, ICON 15, JMA 20, TMD 30 MCM น้ำหนัก 0.3/0.15/0.2/0.2/0.15
- P50 = 0.3×18 + 0.15×25 + 0.2×15 + 0.2×20 + 0.15×30 = 5.4 + 3.75 + 3 + 4 + 4.5 = **20.65 MCM**
- ถ้าอ่างรับน้ำเพิ่มได้อีก 20 MCM ก่อนล้น มีแค่ GFS (25) กับ TMD (30) ที่เกิน 20 → โอกาสล้น = 0.15 + 0.15 = **30%** (JMA 20 พอดีถือว่ายังไม่ล้น)

## ใช้ในโปรเจกต์นี้อย่างไร
ผลส่งไปทั้งงาน 1 (รวมสิ้นเดือน) และงาน 2 (น้ำล้นอ่างลงลำน้ำ)
