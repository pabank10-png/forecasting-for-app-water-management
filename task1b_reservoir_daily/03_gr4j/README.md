# GR4J

- กลุ่ม: Hydrology (Conceptual)
- ทำอะไร: ถังเก็บน้ำ 4 พารามิเตอร์ ฝน → น้ำท่า
- ข้อมูลที่ใช้: ฝน + การระเหย
- สถานะ: ยังไม่เริ่ม

## หลักการ
Conceptual hydrology model จากฝรั่งเศส มองลุ่มน้ำเป็นถัง 2 ใบ ใบแรกคือ "ถังดิน" (production store) รับฝนแล้วเก็บไว้ ส่วนที่ล้นถังกลายเป็นน้ำท่า ใบสองคือ "ถังลำน้ำ" (routing store) ค่อยๆ ปล่อยน้ำออก มีพารามิเตอร์แค่ 4 ตัว
- x1 ความจุถังดิน (mm)
- x2 การแลกน้ำใต้ดิน (mm/วัน)
- x3 ความจุถังลำน้ำ (mm)
- x4 เวลาของ Unit hydrograph (วัน)

## สูตร (ส่วนถังดิน วันที่ฝนมากกว่าการระเหย)
Pn = P − E (ฝนสุทธิ)
Ps = x1·(1 − (S/x1)²)·tanh(Pn/x1) / (1 + (S/x1)·tanh(Pn/x1)) ← ส่วนที่ดินรับไว้
Pr = Pn − Ps ← ส่วนที่ไหลต่อไปเป็นน้ำท่า (ผ่าน Unit hydrograph และถังลำน้ำ)
แปลงเป็นปริมาตร: MCM = mm × พื้นที่ (km²) / 1000

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
x1 = 300 mm, น้ำในถังดิน S = 150 mm, ฝน P = 20 mm, ระเหย E = 4 mm → Pn = 16 mm
- S/x1 = 0.5, tanh(16/300) = 0.0533
- Ps = 300×(1 − 0.25)×0.0533 / (1 + 0.5×0.0533) = 11.99 / 1.0267 = **11.68 mm**
- Pr = 16 − 11.68 = **4.32 mm** (ดินครึ่งถังรับฝนไว้ 73%)
- ถ้าลุ่มน้ำหน้าอ่าง 300 km² → 4.32 × 300 / 1000 = **1.30 MCM** ทยอยไหลเข้าอ่างใน x4 วันถัดไป
ถ้าดินชุ่มกว่านี้ (S สูง) Ps จะลดลง Pr จะเพิ่ม คือฝนเท่ากันแต่น้ำเข้าอ่างมากขึ้น

## ใช้ในโปรเจกต์นี้อย่างไร
ใช้ไลบรารี `hydrotoolbox` หรือเขียนเองสั้นๆ calibrate x1–x4 ต่ออ่างด้วยฝนรายวันและ inflow จริง ใช้ ERA5-Land soil moisture ตรวจว่า S ของโมเดลขึ้นลงสอดคล้องจริง
