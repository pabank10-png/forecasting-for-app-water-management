# ESP + Regression (14_esp_blend)

- กลุ่ม: Hydrology (Physics) + Statistics
- ทำอะไร: ทาย inflow รายเดือน 1–12 เดือน โดยเอาโมเดลน้ำท่า HBV + GR4J แบบ ESP มาเฉลี่ยกับ Regression
- ข้อมูลที่ใช้: inflow รายวัน, ฝนรายวันของลุ่มน้ำ (ยอดฝนรายเดือนของอำเภอ กระจายเป็นรายวันตามรูปแบบฝน ERA5), inflow และฝนรายเดือน
- สถานะ: ใช้งานได้ ทดสอบกับข้อมูลจริงแล้ว (ทดลอง 2026-11-08 ใน experiments/esp_task1)

## หลักการ
ESP (Ensemble Streamflow Prediction) คือวิธีที่หน่วยงานน้ำหลายประเทศใช้พยากรณ์ล่วงหน้าเป็นเดือน

1. ปรับค่า (calibrate) HBV และ GR4J รายวันกับข้อมูล 13 ปีล่าสุดก่อนวันพยากรณ์
2. รันโมเดลด้วยฝนจริงจนถึงวันพยากรณ์ ทำให้รู้ว่าตอนนี้ดินและน้ำใต้ดินชุ่มแค่ไหน แล้วปรับถังน้ำใต้ดินของ HBV ให้ inflow 30 วันล่าสุดตรงกับที่วัดได้ (state updating)
3. จากวันนั้น เอาฝนของแต่ละปีในอดีต (วันที่เดียวกัน) มาป้อนทีละปี ได้ inflow 1 ชุดต่อปี (ประมาณ 20–30 ชุด)
4. แก้ bias รายเดือนด้วยอัตราส่วน inflow จริง/จำลองของเดือนนั้นในช่วง calibrate, เฉลี่ย HBV กับ GR4J แล้วเอา Median ของทุกชุด
5. Regression (climrain): sqrt(inflow) ของเดือนเป้าหมาย จาก inflow และฝนของเดือนล่าสุด (ฝนอนาคตยังไม่รู้ จึงให้เป็นค่าปกติ)
6. P50 = (ESP + Regression) / 2, P10/P90 จาก log error ของวิธีนี้เองใน 6 ปีก่อนวันพยากรณ์ แยกตามเดือนล่วงหน้า

THREE = DK + KY + NPL รวมกันทีละชุดฝน เดือนปัจจุบัน (ยังไม่จบเดือน) = inflow ที่ไหลเข้าแล้วจริง + ESP ของวันที่เหลือ

## ฝนรายวัน (common/daily_rain.py)
เกจฝนที่เขื่อนมีถึง ก.ย. 2020 และประแสร์ไม่มีเกจรายวันเลย จึงสร้างฝนรายวันแบบเดียวกันทุกปี:
ยอดฝนรายเดือนที่โมเดลรายเดือนใช้ (rain_lag0_mm) × สัดส่วนฝนแต่ละวันจาก ERA5 (Open-Meteo, ฟรี, ตั้งแต่ 1994)
ทดสอบ 2014–2020 เทียบเกจจริง: HBV ได้ MAE รายเดือน NPL 8.5 (เกจจริง 8.2), DK 4.8 (5.2), KY 5.6 (5.0) MCM
ERA5 ดิบอย่างเดียวแย่กว่า (NPL 10.2) ข้อมูล ERA5 เก็บไว้ที่ data/raw/era5_rain_daily.csv ดึงเพิ่มเฉพาะวันที่ขาด

## สูตรตัวอย่าง (ตัวเลขสมมติ)
ESP 25 ชุด ของ พ.ย. ได้ Median 47 MCM, Regression ได้ 41 MCM → P50 = (47 + 41)/2 = 44 MCM
log error ในอดีตของ 2 เดือนล่วงหน้า: P10 = −0.62, P90 = +0.71 → P10 = 44.1×e^−0.62 − 0.1 ≈ 23.6, P90 ≈ 89.7 MCM
