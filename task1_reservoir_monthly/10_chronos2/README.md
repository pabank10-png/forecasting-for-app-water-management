# Chronos-2 (Amazon)

- กลุ่ม: Deep Learning (Foundation Model)
- ทำอะไร: ทายได้ทันทีไม่ต้องฝึก รับตัวแปรร่วม
- ข้อมูลที่ใช้: inflow + exog
- สถานะ: เขียนโค้ดแล้ว ยังไม่ได้ทดสอบ (ต้องติดตั้ง torch + แพ็กเกจของโมเดล และโหลด weights)

## หลักการ
Foundation model (Amazon Chronos-2) ที่ train มาแล้วกับอนุกรมเวลานับล้านชุดทั่วโลก ใช้ได้ทันทีแบบ zero-shot ไม่ต้อง train กับข้อมูลเรา ทำงานคล้าย Language model: แปลงตัวเลขเป็นสเกลมาตรฐาน แล้วทำนายค่าถัดไปเป็นการแจกแจง จึงได้ P10/P50/P90 ออกมาเลย และรับตัวแปรภายนอก (covariates) ได้ด้วย

## สูตร
1. Scaling: x' = x / mean(|context|)
2. Transformer ทำนาย quantile ของ x' ในอนาคต
3. แปลงกลับ: ŷ = x̂' × mean(|context|)

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
context 24 เดือนล่าสุดมีค่าเฉลี่ย 30 MCM → หารทุกค่าด้วย 30
โมเดลทาย ต.ค. ในสเกลมาตรฐาน: P10 = 2.4, P50 = 3.5, P90 = 6.0
- แปลงกลับ: P10 = 72, P50 = **105**, P90 = 180 MCM

## ใช้ในโปรเจกต์นี้อย่างไร
`chronos-forecasting` (ต้องติดตั้ง torch) ส่ง inflow ย้อนหลังเป็น context ฝนพยากรณ์และ ENSO เป็น covariates
