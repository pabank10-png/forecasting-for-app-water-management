# Chronos-2 fine-tune

- กลุ่ม: Deep Learning (Foundation Model)
- ทำอะไร: ปรับจูนด้วยข้อมูลอ่างเรา ถ้า zero-shot ใกล้เคียงแต่ยังไม่ชนะ
- ข้อมูลที่ใช้: inflow + ฝน + ความชื้นดิน + ENSO (ONI) + IOD (DMI)
- Lag: ประวัติทั้งหมดของ inflow และตัวแปรอื่นเป็น past covariates
- สถานะ: ใช้งานได้ ทดสอบกับข้อมูลจริงแล้ว

## หลักการ
เอา Chronos-2 ที่ train มาแล้วมาสอนต่อ (fine-tune) ด้วยข้อมูลอ่างของเราเองไม่กี่รอบ ด้วย learning rate ต่ำ ให้ปรับเข้ากับพฤติกรรมเฉพาะของภาคตะวันออก แต่ยังจำความรู้ทั่วไปไว้

## สูตร
w_ใหม่ = w_เดิม − η·∇Loss (η เล็กมาก เช่น 1e-5, train ไม่กี่ร้อย step)
Loss = Quantile loss ของ P10/P50/P90 บนข้อมูลอ่าง 2006–ปีก่อนหน้า

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
zero-shot ทาย ต.ค. P50 = 105 แต่ในอดีตโมเดลทายต่ำกว่าจริงในเดือนที่ ONI สูงเฉลี่ย 15%
หลัง fine-tune โมเดลเรียนรู้ส่วนนี้ ปี 2026 ONI lag1 = 2.16 (สูง) → P50 ขยับเป็น ≈ 105×1.15 = **121 MCM**
(15% เป็นตัวเลขสมมติ ต้องพิสูจน์ด้วย backtest ว่า fine-tune ดีกว่า zero-shot จริง)

## ใช้ในโปรเจกต์นี้อย่างไร
ทำทีหลัง zero-shot ต้องใช้เครื่องที่มี torch และข้อมูลไม่ควรรั่ว (train เฉพาะปีก่อนปีที่ทดสอบ)
