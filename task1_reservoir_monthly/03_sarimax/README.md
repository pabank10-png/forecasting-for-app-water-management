# SARIMAX

- กลุ่ม: Statistics (Time Series)
- ทำอะไร: โมเดลฤดูกาลมาตรฐาน ใส่ฝน ENSO IOD และความชื้นดินเป็นตัวแปรภายนอก
- ข้อมูลที่ใช้: inflow + ฝน + ความชื้นดิน + ENSO (ONI) + IOD (DMI)
- Lag: inflow: AR lag 1 + seasonal lag 12 | ฝน lag 1, ฝนรวม 3 เดือน lag 1, ความชื้นดิน lag 1, ONI lag 1, DMI lag 1
- สถานะ: ใช้งานได้ ทดสอบกับข้อมูลจริงแล้ว

## หลักการ
Statistical model ที่อธิบาย inflow เดือนนี้ด้วย 3 ส่วน
1. AR: inflow เดือนก่อนๆ
2. MA: ความคลาดเคลื่อนของเดือนก่อนๆ
3. Seasonal: ผลของเดือนเดียวกันปีก่อน (ช่วง 12 เดือน)
แล้วบวกตัวแปรภายนอก (X = exogenous) เช่น ฝน ENSO IOD ความชื้นดิน เข้าไปแบบเส้นตรง

## สูตร (แบบย่อ SARIMAX(1,0,0)(1,0,0)12)
ŷ(t) = c + φ·y(t−1) + Φ·y(t−12) + β₁·rain(t) + β₂·sm_root_lag1(t) + …
ช่วง P10/P90 = ŷ ± 1.28·σ (σ คือ Standard deviation ของ error ที่โมเดลประเมินเอง)
ทำบน log(1+inflow) เพราะ inflow เบ้ขวา แล้วแปลงกลับตอนท้าย

## ตัวอย่างการคำนวณ (ค่าสัมประสิทธิ์เป็นตัวเลขสมมติ เพื่อดูกลไก)
สมมติ c = 5, φ = 0.3, Φ = 0.4, β₁ = 0.15, β₂ = 40 (ทำบนหน่วย MCM ตรงๆ ให้เห็นง่าย)
ข้อมูลจริงสำหรับ ต.ค. 2026: y(ก.ย. 2026) = 140.368, y(ต.ค. 2025) = 73.152, rain = 175.06 mm, sm_root_lag1 = 0.4675
- 5 + 0.3×140.368 + 0.4×73.152 + 0.15×175.06 + 40×0.4675
- = 5 + 42.11 + 29.26 + 26.26 + 18.70 = **121.33 MCM**
ถ้า σ = 25 → P10 = 121.33 − 32 = 89.3, P90 = 121.33 + 32 = 153.3
