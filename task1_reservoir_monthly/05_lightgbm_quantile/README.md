# LightGBM quantile

- กลุ่ม: Machine Learning (Gradient-Boosted Trees)
- ทำอะไร: ตัวหลัก ทาย P10/P50/P90 จากทุกคอลัมน์ในชีต LAG
- ข้อมูลที่ใช้: ชีต LAG ทั้งหมด
- สถานะ: ยังไม่เริ่ม

## หลักการ
Gradient boosting สร้าง Decision tree เล็กๆ ทีละต้น แต่ละต้นเรียนรู้ส่วนที่ต้นก่อนหน้าทายพลาด แล้วรวมผลทุกต้น ใช้ loss แบบ Quantile (Pinball loss) จึง train แยก 3 โมเดลได้ P10, P50, P90 โดยตรง จับความสัมพันธ์ไม่เป็นเส้นตรงได้ เช่น ฝนตกบนดินที่ชุ่มแล้ว น้ำไหลเข้ามากกว่าฝนเท่ากันบนดินแห้ง

## สูตร
- พยากรณ์ = ค่าเริ่มต้น + η·tree₁(x) + η·tree₂(x) + … (η = learning rate)
- Pinball loss สำหรับ quantile q: L = q·(y−ŷ) ถ้า y ≥ ŷ, และ (1−q)·(ŷ−y) ถ้า y < ŷ

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ 3 ต้น, η = 0.1)
ค่าเริ่มต้น (Median ของ train) = 40 ข้อมูลจริง ต.ค. 2026: rain = 175.06, sm_root_lag1 = 0.4675, month = 10
- tree₁: ถ้า rain > 150 → +400 มิฉะนั้น −50 → ได้ +400
- tree₂: ถ้า sm_root_lag1 > 0.45 → +250 → ได้ +250
- tree₃: ถ้า month ∈ {9,10} → +60 → ได้ +60
- P50 = 40 + 0.1×(400 + 250 + 60) = 40 + 71 = **111 MCM**

ตัวอย่าง Pinball loss ที่ q = 0.9: ถ้าจริง 136.6 แต่ทาย 111 → L = 0.9×25.6 = 23.0 แต่ถ้าทายเกิน 25.6 → L = 0.1×25.6 = 2.56 โมเดล P90 จึงถูกดันให้ทายสูง

## ใช้ในโปรเจกต์นี้อย่างไร
`lightgbm` ตั้ง `objective="quantile", alpha=0.1/0.5/0.9` ใช้ทุกคอลัมน์ใน MODEL_INPUTS (ฝน lag, ENSO, IOD, ความชื้นดิน, เดือน)
