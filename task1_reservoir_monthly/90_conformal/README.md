# Conformal prediction

- กลุ่ม: Post-processing
- ทำอะไร: ปรับช่วง P10–P90 ให้ครอบค่าจริง 80%
- ข้อมูลที่ใช้: ผลของโมเดลใดก็ได้
- สถานะ: ใช้งานได้ ทดสอบกับข้อมูลจริงแล้ว

## หลักการ
ไม่ใช่โมเดลพยากรณ์ แต่เป็นตัว "ปรับช่วง P10–P90" ให้ครอบคลุมจริงตามที่สัญญา (80%) โดยดูว่าในอดีตช่วงของโมเดลพลาดไปเท่าไร แล้วขยายหรือหดช่วงเท่านั้น (Conformalized Quantile Regression, CQR)

## สูตร
1. ในชุด calibration คำนวณคะแนนแต่ละเดือน: s = max(P10 − y, y − P90) (ติดลบ = อยู่ในช่วง)
2. หา q̂ = Quantile ที่ 80% ของคะแนน s
3. ช่วงใหม่ = [P10 − q̂, P90 + q̂]

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ 5 เดือน)
คะแนน s = −10, −4, +6, +12, −2 → เรียง: −10, −4, −2, +6, +12 → Quantile 80% ≈ +6
โมเดลทาย ต.ค. P10 = 89, P90 = 153
- ช่วงใหม่ = [89 − 6, 153 + 6] = **[83, 159] MCM**
ถ้า q̂ ติดลบ (โมเดลช่วงกว้างเกิน) ช่วงจะหดลงแทน

## ใช้ในโปรเจกต์นี้อย่างไร
ใช้ครอบทุกโมเดลก่อนส่งผล วัดผลด้วย coverage ใน `common/metrics.py` ต้องใกล้ 0.80
