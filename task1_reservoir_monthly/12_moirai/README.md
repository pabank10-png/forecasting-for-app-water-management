# Moirai 2.0 (Salesforce)

- กลุ่ม: Deep Learning (Foundation Model)
- ทำอะไร: รับหลายตัวแปร
- ข้อมูลที่ใช้: inflow + exog
- สถานะ: เขียนโค้ดแล้ว ยังไม่ได้ทดสอบ (ต้องติดตั้ง torch + แพ็กเกจของโมเดล และโหลด weights)

## หลักการ
Foundation model ของ Salesforce เด่นที่รับหลายตัวแปรพร้อมกัน (inflow + ฝน + ENSO) ด้วย Any-variate attention และให้ผลเป็นการแจกแจงผสม (mixture) จึงแสดงความเป็นไปได้ทั้ง "ปีปกติ" และ "ปีน้ำมาก" ได้ในคราวเดียว

## สูตร
พยากรณ์ = Σ wₖ·Distₖ (ผสมหลายการแจกแจง เช่น Student-t, Log-normal) แล้วอ่าน P10/P50/P90 จากการแจกแจงผสม

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
โมเดลให้ 2 ส่วน: ปีปกติ (w = 0.7, กลาง 90) และปีน้ำมาก (w = 0.3, กลาง 180)
- ค่าคาดหมาย = 0.7×90 + 0.3×180 = 63 + 54 = **117 MCM**
- P90 จะอยู่ในฝั่งปีน้ำมาก (~185) ช่วงจึงกว้างกว่าโมเดลที่มีหัวเดียว

## ใช้ในโปรเจกต์นี้อย่างไร
`uni2ts` (Moirai) zero-shot ส่ง inflow เป็นเป้าหมาย ฝน/ENSO/ความชื้นดินเป็นตัวแปรร่วม
