# Water Balance (runSc)

- กลุ่ม: Water Balance
- ทำอะไร: ปริมาตรสิ้นเดือน = ต้นเดือน + inflow × ตัวคูณ + ผันเข้า − ระบาย ตัดที่ 0..ความจุ แบบเดียวกับ water-dashboard
- ข้อมูลที่ใช้: inflow พยากรณ์ + ค่าระบาย/ผันที่ผู้ใช้กรอก
- สถานะ: ใช้งานได้

## หลักการ
ไม่ใช่โมเดลทาย inflow แต่แปลงพยากรณ์ inflow เป็น "ปริมาณน้ำในอ่างปลายเดือน" ด้วยสมดุลน้ำ เหมือนหน้า water-dashboard เดิม (`runSc`) คือ น้ำต้นงวด + น้ำเข้า + น้ำผัน − น้ำปล่อย แล้วตัดไม่ให้ต่ำกว่า 0 หรือเกินความจุ

## สูตร
S(ปลาย) = clamp( S(ต้น) + inflow×multiplier + diversion − outflow , 0 , capacity )
3 อ่างรวม: capacity 318.1, Hard Red 31.7 MCM / ประแสร์: capacity 295, Hard Red 20 MCM (ค่าใน `RESERVOIRS` ของ `model.py`)

## ตัวอย่างการคำนวณ (ข้อมูลจริง ต.ค. 2026, 3 อ่างรวม)
น้ำต้นเดือน 285.545, outflow ทั้งเดือน (สมมติเท่าที่ปล่อยจริงถึงตอนนี้) 125.936, ไม่มีน้ำผัน, multiplier = 1
- ใช้ P50 inflow ของ Climatology = 105.99: 285.545 + 105.99 − 125.936 = **265.60 MCM** (83% ของความจุ)
- ใช้ P90 = 183.84: 285.545 + 183.84 − 125.936 = 343.45 → เกินความจุ จึงตัดเหลือ **318.1** (ล้นประมาณ 25.3 MCM)

```python
from model import run
run(285.545, [105.99], [125.936], capacity=318.1)  # [265.599]
```
