# N-HiTS

- กลุ่ม: Deep Learning (Neural Network)
- ทำอะไร: เหมาะช่วงยาว 12 เดือน ฝึกรวมทุกอ่าง
- ข้อมูลที่ใช้: inflow + ฝน + ENSO + ความชื้นดิน + ปริมาตร
- สถานะ: ใช้งานได้ ทดสอบกับข้อมูลจริงแล้ว

## หลักการ
ต่อยอด N-BEATS โดยให้แต่ละ block ดูข้อมูลคนละความละเอียด block แรกย่อข้อมูลหยาบมาก (เช่นเฉลี่ยทีละ 4 เดือน) เพื่อจับภาพใหญ่ block ถัดไปละเอียดขึ้นเพื่อจับรายละเอียด แล้ว interpolate กลับมาเป็นรายเดือน ทำนายระยะยาว (12 เดือน) ได้ดีและใช้พารามิเตอร์น้อยกว่า

## สูตร
input ย่อ = MaxPool(y ย้อนหลัง, ขนาด k) → MLP → ค่าที่จุดหยาบ → interpolate เป็นรายเดือน → รวมทุก block

## ตัวอย่างการคำนวณ (ข้อมูลจริงปี 2025 ของ 3 อ่างรวม)
inflow ม.ค.–ธ.ค. 2025 = 14.5, 14.5, 12.6, 17.9, 42.2, 22.2, 25.6, 18.5, 64.9, 73.2, 42.6, 15.9
- MaxPool ขนาด 4 → [17.9, 42.2, 73.2] คือภาพใหญ่ "ต้นปีน้อย กลางปีเพิ่ม ปลายปีสูงสุด"
- block นี้ทายจุดหยาบ 3 จุดของปีหน้า สมมติ [18, 40, 75] แล้ว interpolate เป็น 12 เดือน
- block ละเอียด (k = 1) เติมส่วนต่างรายเดือน เช่น ต.ค. +8 จึงได้ ต.ค. ≈ 75 + 8 = 83
