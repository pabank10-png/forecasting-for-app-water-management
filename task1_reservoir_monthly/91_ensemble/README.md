# Ensemble

- กลุ่ม: Post-processing
- ทำอะไร: เฉลี่ยถ่วงน้ำหนักตัวที่ดีที่สุด 2–3 ตัว
- ข้อมูลที่ใช้: ผลของโมเดล
- สถานะ: ยังไม่เริ่ม

## หลักการ
รวมหลายโมเดลเป็นคำตอบเดียว ให้น้ำหนักตามความแม่นในอดีต (โมเดลที่ MAE ต่ำได้น้ำหนักมาก) แล้วหดน้ำหนักเข้าหาค่าเท่ากัน (shrink) กันไม่ให้เชื่อโมเดลเดียวมากเกินไป ทีม Council เลือก "แชมป์" เดี่ยว และใช้ Ensemble เฉพาะเมื่อดีกว่าแชมป์อย่างน้อย 2%

## สูตร
- น้ำหนักดิบ: wᵢ = (1/MAEᵢ) / Σ(1/MAEⱼ)
- หดน้ำหนัก: wᵢ' = λ·wᵢ + (1−λ)·(1/n), λ = 0.5
- ŷ = Σ wᵢ'·ŷᵢ

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ 2 โมเดล)
LightGBM MAE = 10, SARIMAX MAE = 20
- น้ำหนักดิบ: (1/10)/(1/10+1/20) = 0.667 และ 0.333
- หดน้ำหนัก: 0.5×0.667 + 0.5×0.5 = 0.583 และ 0.5×0.333 + 0.25 = 0.417
- พยากรณ์ LightGBM 100, SARIMAX 130 → 0.583×100 + 0.417×130 = **112.5 MCM**
