# LSTM / Encoder–decoder LSTM

- กลุ่ม: Deep Learning (Neural Network)
- ทำอะไร: ตัวเทียบ deep learning แบบอนุกรม
- ข้อมูลที่ใช้: เหมือน N-HiTS
- สถานะ: ยังไม่เริ่ม

## หลักการ
Recurrent Neural network ที่อ่านข้อมูลทีละเดือนตามลำดับเวลา และมี "หน่วยความจำ" (cell state) จำสิ่งสำคัญไว้นาน เช่น ฝนสะสมหลายเดือนที่ทำให้ดินชุ่ม มีประตู 3 บาน (gate) ตัดสินว่าจะลืม จะรับเพิ่ม และจะส่งออกเท่าไร

## สูตร
- forget gate f, input gate i, output gate o มีค่า 0–1 (sigmoid)
- c̃ = tanh(…) คือข้อมูลใหม่
- c(t) = f·c(t−1) + i·c̃
- h(t) = o·tanh(c(t)) → นำ h ไปคำนวณพยากรณ์

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ 1 หน่วย)
f = 0.8, i = 0.3, c̃ = 0.5, c(t−1) = 1.0, o = 0.6
- c(t) = 0.8×1.0 + 0.3×0.5 = 0.95 (จำของเก่าไว้ 80% รับของใหม่ 30%)
- h(t) = 0.6×tanh(0.95) = 0.6×0.740 = 0.444
ถ้าชั้นสุดท้าย ŷ = 20 + 200·h → 20 + 88.8 = **108.8 MCM** (หลังแปลงสเกลกลับ)
