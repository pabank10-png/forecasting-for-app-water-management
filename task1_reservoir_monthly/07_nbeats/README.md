# N-BEATS / NBEATSx

- กลุ่ม: Deep Learning (Neural Network)
- ทำอะไร: แยก trend และฤดูกาลจากอดีต
- ข้อมูลที่ใช้: inflow (+ exog)
- สถานะ: ใช้งานได้ ทดสอบกับข้อมูลจริงแล้ว

## หลักการ
Deep Learning แบบ Neural network หลายชั้นเรียงกันเป็น block รับ inflow ย้อนหลัง (เช่น 24 เดือน) แล้วแต่ละ block ทำ 2 อย่าง: ส่งส่วนที่อธิบายได้ไปเป็นพยากรณ์ และลบส่วนนั้นออกจาก input ส่งที่เหลือ (residual) ให้ block ถัดไป แบบ interpretable จะแยกเป็น block แนวโน้ม (trend) และ block ฤดูกาล (seasonality)

## สูตร
- block แนวโน้ม: ŷ(h) = θ₀ + θ₁·h (+ θ₂·h²) โดย θ มาจาก Neural network
- block ฤดูกาล: ŷ(h) = Σ [aₖ·cos(2πkh/12) + bₖ·sin(2πkh/12)]
- พยากรณ์รวม = ผลรวมของทุก block

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
block แนวโน้มให้ θ = (50, 2) → h = 1, 2, 3 ได้ 52, 54, 56
block ฤดูกาลให้ +60, +5, −30 (ต.ค. สูง, พ.ย. กลาง, ธ.ค. ต่ำ)
- พยากรณ์ ต.ค./พ.ย./ธ.ค. = 112, 59, 26 MCM

## ใช้ในโปรเจกต์นี้อย่างไร
`neuralforecast.models.NBEATS` ใช้ inflow อย่างเดียว ข้อมูลรายเดือนมีไม่มาก (~240 เดือน) จึงต้องเทียบให้ดีว่าไม่ Overfit
