# ETS (Holt-Winters)

- กลุ่ม: Statistics (Time Series)
- ทำอะไร: ตัวเทียบสถิติแบบง่าย แยกระดับ แนวโน้ม และฤดูกาล
- ข้อมูลที่ใช้: inflow
- สถานะ: ใช้งานได้ ทดสอบกับข้อมูลจริงแล้ว

## หลักการ
Exponential Smoothing (ETS = Error, Trend, Seasonal) ให้น้ำหนักข้อมูลล่าสุดมากที่สุด แล้วน้ำหนักลดลงแบบ exponential กับข้อมูลเก่า แยกเก็บ 3 ส่วน: ระดับ (level), แนวโน้ม (trend), ฤดูกาล (season)

## สูตร (Holt-Winters แบบบวก ไม่มี trend)
- level: ℓ(t) = α·(y(t) − s(t−12)) + (1−α)·ℓ(t−1)
- season: s(t) = γ·(y(t) − ℓ(t)) + (1−γ)·s(t−12)
- พยากรณ์ h เดือนข้างหน้า: ŷ(t+h) = ℓ(t) + s(t+h−12)

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
α = 0.3, γ = 0.2, ℓ(ส.ค.) = 40, ค่าฤดูกาลของ ก.ย. s(ก.ย.ปีก่อน) = +35, inflow จริง ก.ย. = 140.368
- ℓ(ก.ย.) = 0.3×(140.368 − 35) + 0.7×40 = 31.61 + 28 = 59.61
- s(ก.ย.) = 0.2×(140.368 − 59.61) + 0.8×35 = 16.15 + 28 = 44.15
- ถ้าค่าฤดูกาลของ ต.ค. = +55 → ŷ(ต.ค.) = 59.61 + 55 = **114.61 MCM**

## ใช้ในโปรเจกต์นี้อย่างไร
ใช้ `statsmodels.tsa.holtwinters` หรือ `statsforecast.AutoETS` (เลือก α γ ให้เองอัตโนมัติ) ใช้ inflow อย่างเดียว ไม่ใช้ฝน เป็นตัวเทียบว่าตัวแปรภายนอกช่วยจริงไหม
