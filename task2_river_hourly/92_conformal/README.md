# Conformal

- กลุ่ม: Post-processing
- ทำอะไร: ช่วงพยากรณ์ที่เชื่อถือได้
- ข้อมูลที่ใช้: ผลของโมเดล
- สถานะ: ยังไม่เริ่ม

## หลักการ
ปรับช่วง P10–P90 ของระดับน้ำให้ครอบคลุมจริง 80% โดยดูความผิดพลาดของช่วงในอดีต แยกต่อระยะล่วงหน้า (ระยะไกลมักต้องขยายช่วงมากกว่า) ใช้วิธี CQR เดียวกับ `task1_reservoir_monthly/90_conformal`

## สูตร
s = max(P10 − y, y − P90) ในชุด calibration → q̂ = Quantile 80% ของ s → ช่วงใหม่ [P10 − q̂, P90 + q̂]

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ +12 ชม.)
คะแนน 5 ครั้งล่าสุด: −0.10, +0.05, −0.02, +0.15, +0.08 → เรียง −0.10, −0.02, +0.05, +0.08, +0.15 → Quantile 80% ≈ +0.08
โมเดลทาย P10 = 2.60, P90 = 3.10
- ช่วงใหม่ = **[2.52, 3.18] m**

## ใช้ในโปรเจกต์นี้อย่างไร
ทำหลังสุดก่อนส่งผล วัดด้วย coverage ต้องใกล้ 0.80 ทุกระยะ
