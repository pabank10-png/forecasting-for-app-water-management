# Muskingum routing

- กลุ่ม: Hydrology
- ทำอะไร: การเคลื่อนตัวของคลื่นน้ำในลำน้ำ
- ข้อมูลที่ใช้: ปริมาณน้ำไหล (Q)
- สถานะ: ยังไม่เริ่ม

## หลักการ
Hydrologic routing คำนวณว่าคลื่นน้ำ (ปริมาณน้ำไหล Q) ที่ไหลเข้าช่วงลำน้ำจะออกปลายช่วงหน้าตาเป็นอย่างไร ลำน้ำเก็บน้ำไว้ส่วนหนึ่ง ทำให้ยอดคลื่นที่ปลายช่วงต่ำลงและมาช้ากว่า
- K = เวลาเดินทางของคลื่นผ่านช่วงลำน้ำ
- X = น้ำหนักของน้ำเข้าเทียบน้ำออก (0–0.5)

## สูตร
O₂ = C₀·I₂ + C₁·I₁ + C₂·O₁
- C₀ = (Δt − 2KX) / (2K(1−X) + Δt)
- C₁ = (Δt + 2KX) / (2K(1−X) + Δt)
- C₂ = (2K(1−X) − Δt) / (2K(1−X) + Δt)
- C₀ + C₁ + C₂ = 1

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
K = 6 ชม., X = 0.2, Δt = 3 ชม. → ตัวหาร = 2×6×0.8 + 3 = 12.6
- C₀ = (3 − 2.4)/12.6 = 0.0476, C₁ = (3 + 2.4)/12.6 = 0.4286, C₂ = (9.6 − 3)/12.6 = 0.5238
- น้ำเข้า I₁ = 100, I₂ = 150 m³/s, น้ำออกก่อนหน้า O₁ = 90 m³/s
- O₂ = 0.0476×150 + 0.4286×100 + 0.5238×90 = 7.14 + 42.86 + 47.14 = **97.14 m³/s**
(น้ำเข้าขึ้นเป็น 150 แต่น้ำออกเพิ่มเป็นแค่ 97 เพราะลำน้ำหน่วงไว้)

## ใช้ในโปรเจกต์นี้อย่างไร
ใช้ส่งน้ำล้นอ่าง (จากงาน 1B) และน้ำท่าจากฝนลงไปตามลำน้ำถึงจุดเสี่ยงท่วม ต้องแปลงระดับ ↔ Q ด้วย Rating curve ของสถานี
