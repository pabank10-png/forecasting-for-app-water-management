# Chronos-2, TimesFM 2.5 (zero-shot)

- กลุ่ม: Deep Learning (Foundation Model)
- ทำอะไร: ตัวเทียบแบบไม่ต้องฝึก
- ข้อมูลที่ใช้: ระดับน้ำ
- สถานะ: เขียนโค้ดแล้ว ยังไม่ได้ทดสอบ (ต้องติดตั้ง torch + แพ็กเกจของโมเดล และโหลด weights)

## หลักการ
Foundation model (Chronos-2 / TimesFM / Moirai) แบบไม่ต้อง train ส่งระดับน้ำย้อนหลังให้ แล้วได้พยากรณ์ 1–48 ชม. พร้อมช่วง ใช้วัดว่าโมเดลที่ train เองคุ้มค่าหรือไม่ และใช้ได้ทันทีกับสถานีใหม่ที่ยังมีข้อมูลน้อย

## สูตร
x' = x / mean(|context|) → Transformer → quantile → × mean(|context|)

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
ระดับ 168 ชม. ล่าสุดเฉลี่ย 2.0 m โมเดลให้ +6 ชม. ในสเกลมาตรฐาน P10/P50/P90 = 1.25/1.40/1.60
- แปลงกลับ = 2.50 / **2.80** / 3.20 m
