# LightGBM / XGBoost (multi-horizon, quantile)

- กลุ่ม: Machine Learning (Gradient-Boosted Trees)
- ทำอะไร: ตัวหลัก 1 โมเดลต่อระยะล่วงหน้า
- ข้อมูลที่ใช้: ระดับหลายสถานี + ฝนสะสม + ฝนพยากรณ์ + การปล่อยน้ำจากโจทย์ 1B
- สถานะ: ยังไม่เริ่ม

## หลักการ
ตัวหลักของงาน 2 Gradient boosting ของ Decision tree แยก 1 โมเดลต่อระยะล่วงหน้า (1, 2, 3, 6, 12, 24, 48 ชม.) และแยก P10/P50/P90 ตัวแปร: ระดับหลายสถานี (ย้อนหลังหลายชั่วโมง) การเปลี่ยนแปลงล่าสุด ฝนสะสม 1/3/6/24 ชม. ฝนพยากรณ์ การปล่อยน้ำ/น้ำล้นจากงาน 1B ช่วงเวลาของวันและน้ำขึ้นน้ำลง (ถ้าใกล้ปากแม่น้ำ)

## สูตร
ŷ_h = ค่าเริ่มต้น + η·Σ treeₖ(x) และใช้ Pinball loss (ดู `task1_reservoir_monthly/05_lightgbm_quantile`)
มักทาย "ส่วนเปลี่ยนแปลง" Δ = y(t+h) − y(t) แทนระดับตรงๆ แล้วบวก y(t) กลับ

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ h = 6 ชม.)
y(t) = 2.55 m ค่าเริ่มต้น Δ = 0, η = 0.1
- tree₁: ฝน 6 ชม. > 40 mm → +2.0 (ฝนจริง 45 mm)
- tree₂: ต้นน้ำขึ้น > 0.3 m ใน 3 ชม. → +1.5 (ขึ้น 0.5 m)
- tree₃: อ่างต้นน้ำล้น spillway → +1.0 (ไม่ล้น → −0.2)
- Δ = 0.1×(2.0 + 1.5 − 0.2) = 0.33 → ŷ = 2.55 + 0.33 = **2.88 m**
