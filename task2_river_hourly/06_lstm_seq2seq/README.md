# LSTM / Encoder–decoder LSTM (Seq2Seq)

- กลุ่ม: Deep Learning (Neural Network)
- ทำอะไร: มาตรฐานงานพยากรณ์น้ำท่วมรายชั่วโมง ฝึกรวมทุกสถานี
- ข้อมูลที่ใช้: เหมือน LightGBM
- สถานะ: ยังไม่เริ่ม

## หลักการ
มาตรฐานของงานพยากรณ์น้ำท่วมรายชั่วโมง (เช่นระบบของ Google Flood Hub) encoder อ่านอดีต 72 ชม. (ระดับ ฝน) decoder อ่านฝนพยากรณ์ทีละชั่วโมงแล้วออกระดับ 1…48 ชม. train รวมทุกสถานีพร้อมกัน จึงเรียนรู้จากน้ำท่วมของหลายจุด

## สูตร
encoder: (h, c) = LSTM(x(t−71)…x(t)), decoder: ŷ(t+k) = W·LSTM(rain_f(t+k) | h, c) + b
c = f·c_เก่า + i·c̃, h = o·tanh(c)

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ 1 หน่วย)
encoder จบที่ c = 0.6 ชั่วโมงแรก decoder รับฝน 20 mm/ชม.: f = 0.95, i = 0.4, c̃ = 0.9, o = 0.8
- c = 0.95×0.6 + 0.4×0.9 = 0.93
- h = 0.8×tanh(0.93) = 0.8×0.731 = 0.585
- Δระดับ = 0.4×0.585 = 0.23 m → ŷ(+1 ชม.) = 2.55 + 0.23 = **2.78 m**
