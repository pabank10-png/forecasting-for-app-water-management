# Travel-time / lag correlation

- กลุ่ม: Hydrology
- ทำอะไร: ระดับต้นน้ำ + เวลาเดินทาง → ระดับท้ายน้ำ
- ข้อมูลที่ใช้: ระดับหลายสถานี
- สถานะ: ยังไม่เริ่ม

## หลักการ
น้ำที่สถานีต้นน้ำจะเดินทางมาถึงสถานีท้ายน้ำหลังเวลาหนึ่ง (travel time) หาเวลานั้นจากข้อมูลอดีตด้วย Cross-correlation (เลื่อนกราฟสองสถานีจนซ้อนกันได้ดีที่สุด) แล้วหาความสัมพันธ์ระหว่างการเปลี่ยนแปลงของสองสถานี

## สูตร
- τ = lag ที่ทำให้ corr(Δy_ต้นน้ำ(t−τ), Δy_ท้ายน้ำ(t)) สูงสุด
- ŷ_ท้ายน้ำ(t+h) = y_ท้ายน้ำ(t) + a·(y_ต้นน้ำ(t+h−τ) − y_ต้นน้ำ(t−τ)) ใช้ได้เมื่อ h ≤ τ

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
พบว่า τ = 6 ชม. และ a = 0.6 ตอนนี้ (12:00) ท้ายน้ำ = 1.80 m
ต้นน้ำ 06:00 = 3.00 m, 09:00 = 3.50 m
- ทายท้ายน้ำ 15:00 (h = 3): 1.80 + 0.6×(3.50 − 3.00) = **2.10 m**
ทายได้ไกลสุด 6 ชม. ถ้าไกลกว่านี้ต้องใช้ระดับต้นน้ำที่พยากรณ์จากโมเดลอื่น

## ใช้ในโปรเจกต์นี้อย่างไร
