# ผลจำลอง 2 มิติ ROD ม.อ.

- กลุ่ม: Hydrology (Physical)
- ทำอะไร: แปลงระดับน้ำเป็นพื้นที่ท่วม 56 ตำบล (ขั้นแผนที่)
- ข้อมูลที่ใช้: ระดับพยากรณ์
- สถานะ: โค้ด Bathtub + ScenarioLookup ทดสอบกับข้อมูลจำลองแล้ว ใช้ผล ม.อ. ต้องขออนุญาตก่อน

## หลักการ
แบบจำลองน้ำท่วม 2 มิติของ ม.อ. (PaYaNaFlood / RODDSS) แปลงระดับน้ำในลำน้ำเป็นพื้นที่น้ำท่วมบนแผนที่ คำนวณน้ำไหลบนผิวดินทุกช่องกริด (Shallow water equations) เป็นขั้น "แผนที่" หลังจากพยากรณ์ระดับน้ำแล้ว

## สูตร (แบบง่ายที่สุดเพื่อดูกลไก: Bathtub)
ความลึกท่วม = ระดับน้ำพยากรณ์ − ระดับพื้นดิน (DEM) ถ้าเป็นบวกและต่อกับลำน้ำ = ท่วม
(แบบ 2D จริงคำนวณการไหลของน้ำระหว่างช่องกริดตามความลาดและความขรุขระ แม่นกว่ามาก)

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
ระดับน้ำพยากรณ์ที่สถานี = +5.20 m รทก. กริด 3 ช่องติดตลิ่งมีระดับพื้น 4.80 / 5.10 / 5.50 m
- ความลึก = 0.40 / 0.10 / ไม่ท่วม → ช่อง 1–2 ท่วม (ช่องละ 30×30 m = 900 m²) รวม 1,800 m²

## ใช้ในโปรเจกต์นี้อย่างไร
แปลงผลเป็นพื้นที่ท่วม 56 ตำบล ต้องขออนุญาตใช้แบบจำลองจาก ม.อ. ก่อน
