# HEC-HMS + HEC-RAS 1D

- กลุ่ม: Hydrology (Physical)
- ทำอะไร: ใช้ได้แม้เหตุการณ์ใหญ่กว่าที่เคยมี
- ข้อมูลที่ใช้: หน้าตัดลำน้ำ + ฝน
- สถานะ: ใช้งานได้ ทดสอบกับข้อมูลจำลองแล้ว (รอข้อมูลรายชั่วโมงจริง) ส่วน HEC-RAS เต็มต้องใช้โปรแกรม HEC

## หลักการ
Physical model ของกองทัพบกสหรัฐฯ 2 ส่วน
- HEC-HMS: แปลงฝนเป็นน้ำท่าในลุ่มน้ำย่อย เช่นด้วยวิธี SCS Curve Number แล้วทำ Unit hydrograph
- HEC-RAS: ส่งน้ำไปตามหน้าตัดลำน้ำจริงด้วยสมการ Saint-Venant ได้ระดับน้ำทุกหน้าตัด
ใช้ได้แม้เหตุการณ์ใหญ่กว่าที่เคยมีในข้อมูล เพราะใช้ฟิสิกส์ ไม่ได้จำจากอดีต

## สูตร (SCS Curve Number ในส่วน HMS)
S = 25400/CN − 254 (mm), Ia = 0.2·S
Q = (P − Ia)² / (P − Ia + S) เมื่อ P > Ia

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
ฝน P = 100 mm, CN = 80 (พื้นที่เกษตรปนชุมชน)
- S = 25400/80 − 254 = 63.5 mm, Ia = 12.7 mm
- Q = (100 − 12.7)² / (100 − 12.7 + 63.5) = 7621.3 / 150.8 = **50.54 mm** (ฝนครึ่งหนึ่งกลายเป็นน้ำท่า)
- ลุ่มน้ำย่อย 50 km² → 50.54 × 50 / 1000 = 2.53 MCM ที่ HEC-RAS จะส่งต่อไปตามลำน้ำ

## ใช้ในโปรเจกต์นี้อย่างไร
ต้องมีหน้าตัดลำน้ำ (cross-section) และ DEM งานใหญ่ ทำหลังโมเดลข้อมูลใช้งานได้แล้ว
