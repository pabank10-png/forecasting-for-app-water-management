# Persistence / Persistence + แนวโน้ม

- กลุ่ม: Baseline
- ทำอะไร: ระดับน้ำ = ค่าล่าสุด (+ แนวโน้ม)
- ข้อมูลที่ใช้: ระดับน้ำรายชั่วโมง
- สถานะ: ยังไม่เริ่ม

## หลักการ
ทายว่าระดับน้ำ h ชั่วโมงข้างหน้าเท่ากับค่าล่าสุด หรือต่อแนวโน้มล่าสุดออกไป (ขึ้นเท่าไรต่อชั่วโมงก็ขึ้นต่อไปเท่านั้น) แม่นมากในชั่วโมงแรกๆ จึงเป็นเกณฑ์ที่โมเดลอื่นต้องชนะ

## สูตร
- แบบคงที่: ŷ(t+h) = y(t)
- แบบมีแนวโน้ม: ŷ(t+h) = y(t) + h·(y(t) − y(t−1))·d โดย d (0–1) ลดแนวโน้มลงเพื่อไม่ให้พุ่งเกินจริง

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
ระดับ 10:00 = 2.40 m, 11:00 = 2.55 m (ขึ้น 0.15 m/ชม.) ใช้ d = 0.7
- +1 ชม.: 2.55 + 1×0.15×0.7 = 2.66 m
- +3 ชม.: 2.55 + 3×0.15×0.7 = 2.87 m
- +6 ชม.: 2.55 + 6×0.15×0.7 = 3.18 m
