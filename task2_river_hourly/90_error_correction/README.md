# Error correction / Kalman

- กลุ่ม: Post-processing (Data Assimilation)
- ทำอะไร: ปรับผลทุกโมเดลด้วยค่าที่วัดได้ชั่วโมงล่าสุด
- ข้อมูลที่ใช้: ผลของโมเดล + ค่าวัดล่าสุด
- สถานะ: ยังไม่เริ่ม

## หลักการ
Data assimilation แบบง่าย: ดูว่าชั่วโมงล่าสุดโมเดลพลาดเท่าไร (ค่าวัดจริง − ค่าที่ทาย) แล้วเอาความผิดพลาดนั้นไปแก้พยากรณ์ข้างหน้า โดยลดผลลงเรื่อยๆ ตามระยะ เพราะ error มักต่อเนื่องในชั่วโมงใกล้ๆ แต่จางไปในระยะไกล ใช้แบบ AR(1)

## สูตร
e(t) = y(t) − ŷ(t)
ŷ_แก้(t+h) = ŷ(t+h) + φ^h · e(t) (φ ประมาณจากข้อมูล 0–1)

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
ชั่วโมงล่าสุดวัดได้ 2.55 m แต่โมเดลทาย 2.25 → e = +0.30, φ = 0.8
- +1 ชม.: แก้เพิ่ม 0.8 × 0.30 = **+0.24 m**
- +3 ชม.: 0.8³ × 0.30 = 0.512 × 0.30 = **+0.154 m**
- +12 ชม.: 0.8¹² × 0.30 = 0.021 m (แทบไม่แก้)
