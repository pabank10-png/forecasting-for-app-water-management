# ARX / ARIMAX

- กลุ่ม: Statistics (Time Series)
- ทำอะไร: สมการเชิงเส้นจากระดับย้อนหลัง + ต้นน้ำ + ฝน
- ข้อมูลที่ใช้: ระดับ + ฝน
- สถานะ: ยังไม่เริ่ม

## หลักการ
AutoRegressive with eXogenous input: สมการเชิงเส้นที่ทายระดับน้ำจากระดับย้อนหลังของตัวเอง ระดับต้นน้ำ และฝนสะสม หาค่าสัมประสิทธิ์ด้วย Least squares แยกสมการต่อระยะล่วงหน้า h

## สูตร
ŷ(t+h) = c + a₁·y(t) + a₂·y(t−1) + b·y_ต้นน้ำ(t) + g·rain_3ชม.(t) + k·rain_พยากรณ์(t…t+h)

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ h = 3 ชม.)
c = 0.10, a₁ = 1.2, a₂ = −0.3, b = 0.08, g = 0.01, k = 0.005
y(t) = 2.55, y(t−1) = 2.40, ต้นน้ำ = 3.50, ฝน 3 ชม. = 25 mm, ฝนพยากรณ์ 3 ชม. = 10 mm
- 0.10 + 3.06 − 0.72 + 0.28 + 0.25 + 0.05 = **3.02 m**
