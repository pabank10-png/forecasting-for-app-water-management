# Ensemble ฝนพยากรณ์หลายโมเดล

- กลุ่ม: Post-processing
- ทำอะไร: ป้อนฝน ECMWF/GFS/ICON/TMD แยกกัน → ช่วงความไม่แน่นอน
- ข้อมูลที่ใช้: ผลของโมเดล
- สถานะ: ใช้งานได้ ทดสอบกับข้อมูลจำลองแล้ว (รอข้อมูลรายชั่วโมงจริง)

## หลักการ
ป้อนฝนพยากรณ์ทีละแหล่ง (ECMWF, GFS, ICON, TMD) เข้าโมเดลระดับน้ำตัวเดียวกัน ได้ระดับน้ำหลายชุด ความต่างของชุดเหล่านั้นคือความไม่แน่นอนที่มาจากฝน ใช้บอก "โอกาสเกินตลิ่ง"

## สูตร
- P50 = Σ wₛ·ŷₛ
- โอกาสเกินตลิ่ง = Σ wₛ × [ŷₛ > ระดับตลิ่ง]

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ +12 ชม., ระดับตลิ่ง 3.00 m)
ECMWF 2.80, GFS 3.20, ICON 2.70, TMD 3.10 m น้ำหนัก 0.35/0.20/0.20/0.25
- P50 = 0.98 + 0.64 + 0.54 + 0.775 = **2.935 m**
- เกินตลิ่ง: GFS + TMD = 0.20 + 0.25 = **45%**

## ใช้ในโปรเจกต์นี้อย่างไร
ใช้กับทุกโมเดลที่รับฝนพยากรณ์ (LightGBM, LSTM, TFT, HEC-HMS) ต้องเก็บฝนพยากรณ์ย้อนหลังของทุกแหล่งไว้ประเมินน้ำหนัก
