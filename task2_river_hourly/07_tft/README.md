# Temporal Fusion Transformer (TFT)

- กลุ่ม: Deep Learning (Neural Network)
- ทำอะไร: แยกตัวแปรอดีต/อนาคต บอกความสำคัญของตัวแปร
- ข้อมูลที่ใช้: เหมือน LightGBM
- สถานะ: ยังไม่เริ่ม

## หลักการ
Temporal Fusion Transformer แยกตัวแปรเป็น 3 ชนิด
1. คงที่ (รหัสสถานี พื้นที่รับน้ำ)
2. อดีตที่รู้แล้ว (ระดับ ฝนจริง)
3. อนาคตที่รู้ล่วงหน้า (ฝนพยากรณ์ เวลาของวัน)
มี Variable selection network ให้น้ำหนักแต่ละตัวแปร จึงอธิบายได้ว่าตัวแปรไหนสำคัญ และ Attention บอกว่าชั่วโมงไหนในอดีตมีผล

## สูตร
น้ำหนักตัวแปร = softmax(GRN(x)) → ξ = Σ wⱼ·GRN(xⱼ) → LSTM → Attention → quantile heads (P10/P50/P90)

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
ตัวแปรอนาคต 3 ตัวมีคะแนนดิบ 2.0 (ฝนพยากรณ์), 1.0 (น้ำล้นอ่าง), 0.0 (เวลาของวัน)
- softmax: e² = 7.39, e¹ = 2.72, e⁰ = 1 รวม 11.11 → น้ำหนัก **0.665, 0.245, 0.090**
แปลว่าโมเดลให้ความสำคัญกับฝนพยากรณ์ 66% ใช้อธิบายให้ผู้บริหารเห็นว่าทำไมโมเดลเตือน
