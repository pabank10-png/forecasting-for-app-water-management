# Hybrid LightGBM + LSTM

- กลุ่ม: Deep Learning (Neural Network)
- ทำอะไร: LightGBM ทายหลัก LSTM แก้ส่วนที่คลาด
- ข้อมูลที่ใช้: เหมือน LightGBM
- สถานะ: ยังไม่เริ่ม

## หลักการ
ให้ LightGBM ทายหลักก่อน แล้วให้ LSTM เรียนรู้ส่วนที่ LightGBM พลาดเป็นลำดับเวลา (residual) เช่นพลาดต่อเนื่องในช่วงน้ำขึ้นเร็ว แล้วเอามาบวกแก้

## สูตร
ŷ = ŷ_LightGBM + r̂_LSTM โดย LSTM train บน r = y − ŷ_LightGBM ของอดีต

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
LightGBM ทาย +6 ชม. = 2.88 m แต่ 6 ชม. ที่ผ่านมามันทายต่ำกว่าจริงเฉลี่ย 0.10 m และพลาดเพิ่มขึ้นเรื่อยๆ
LSTM อ่านลำดับ residual แล้วทายว่าจะพลาด +0.12
- ŷ = 2.88 + 0.12 = **3.00 m**

## ใช้ในโปรเจกต์นี้อย่างไร
ทดสอบหลังมี LightGBM และ LSTM แล้ว ใช้ต่อเมื่อ backtest ดีกว่าแต่ละตัวเดี่ยว
