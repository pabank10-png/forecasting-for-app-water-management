# N-HiTS

- กลุ่ม: Deep Learning (Neural Network)
- ทำอะไร: ทายหลายระยะพร้อมกัน
- ข้อมูลที่ใช้: เหมือน LightGBM
- สถานะ: ยังไม่เริ่ม

## หลักการ
N-HiTS ทายทุกระยะ 1–48 ชม. พร้อมกันในครั้งเดียว แต่ละ block ดูข้อมูลคนละความละเอียด block หยาบจับการขึ้นลงใหญ่ (ทั้งวัน) block ละเอียดจับการเปลี่ยนรายชั่วโมง

## สูตร
MaxPool(ระดับย้อนหลัง, k) → MLP → ค่าที่จุดหยาบ → interpolate เป็นรายชั่วโมง → รวมทุก block

## ตัวอย่างการคำนวณ (ตัวเลขสมมติ)
ระดับ 8 ชม. ล่าสุด 2.0, 2.0, 2.1, 2.1, 2.2, 2.3, 2.4, 2.55
- MaxPool k = 4 → [2.1, 2.55] เห็นภาพ "กำลังขึ้น"
- block หยาบทายจุดหยาบ +12 ชม. = 3.0, +24 ชม. = 2.8 แล้ว interpolate: +6 ชม. ≈ 2.55 + (3.0 − 2.55)×6/12 = 2.78
- block ละเอียดเติม +0.05 → ŷ(+6 ชม.) = **2.83 m**

## ใช้ในโปรเจกต์นี้อย่างไร
`neuralforecast.models.NHITS` เหมาะกับระยะไกล 24–48 ชม.
